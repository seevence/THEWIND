# 数据来源与使用说明

## 采集范围

| 类型 | 来源 | 用途 |
|---|---|---|
| 岗位 | 腾讯 / 美团 / 百度官方招聘页 | 岗位目录、方向/职位趋势、学生友好筛选 |
| 政策 | 中国政府网、国家发改委 | 政策文件、政策与岗位联动 |

## 使用原则

1. **只聚合公开信息**：仅抓取公开可访问页面，展示标题、公司、城市、技能等结构化字段，并保留官方原文链接；
2. **不转载全文**：岗位详情展示观测摘录（限长），以原文为准；政策展示标题、来源、日期与原文链接；
3. **可追溯**：每条岗位/政策都有来源与首次观测时间；
4. **相关性过滤**：政策按「就业 / 人才 / 教育 / 劳动 + 产业发展支持」规则过滤，明显无关的政策不展示；
5. **AI 标注**：研判与日报评论为模型生成，页面标注「后台预生成 / 数据截至 / 置信度」。

## 隐私

- 不收集账号信息；收藏、已读等只存在读者浏览器本地；
- 反馈仅收集读者主动填写的内容；
- 站点访问日志用于运行维护，不用于画像或广告。
